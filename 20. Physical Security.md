# Physical Security

---

## Overview

_Volatile facts (framework versions, requirement numbers, reporting clocks) are maintained in [note 00](00.%20Current%20Versions%20and%20Facts.md). Check it before relying on figures here._

Physical security is the discipline of protecting people, premises, equipment, and information from physical threats — including unauthorised access, theft, vandalism, sabotage, natural disaster, and deliberate destruction. In the Australian context it sits at the intersection of two mandatory legislative and policy regimes: the **Protective Security Policy Framework (PSPF)**, which governs Commonwealth entities, and the **Security of Critical Infrastructure Act 2018 (SOCI Act)**, which governs owners and operators of critical infrastructure across 11 sectors. Physical security is the outermost layer of a defence-in-depth strategy. Every technical control — a firewall, an encrypted drive, a hardened server — can be bypassed if an adversary can physically reach the hardware or facility. Both the PSPF and the SOCI Act treat physical security as a non-negotiable element of an all-hazards risk management posture, not an optional hardening measure.

The discipline spans three areas: people security (controlling who enters and where they can go), asset security (protecting equipment, media, and information containers), and environmental security (protecting against fire, flood, power failure, and other hazards).

---

## Why It Matters

Physical access is frequently the path of least resistance. A threat actor who gains access to a comms room can extract drives, plant keyloggers, or reset credentials — defeating layers of technical controls in minutes.

Real-world consequences when physical security fails:

- **Equipment theft and data extraction**: Unencrypted laptops and unattended removable media remain persistent exposures. Hardware theft bypasses every logical control.
- **Insider-enabled exfiltration**: In 2024, a Google engineer physically removed 500 confidential files containing proprietary AI design data over time. The Ponemon Institute's 2025 Cost of Insider Risks Global Report found the average annual cost of insider threats reached USD $17.4 million per organisation.
- **Tailgating and facility compromise**: Once an unauthorised person is inside, logical access controls may offer limited protection for unlocked workstations, unattended terminals, and physical media.
- **Sabotage of critical infrastructure**: Physical damage to control systems, substations, water treatment facilities, or network infrastructure can cause widespread service disruption. The SOCI Act was expanded specifically because physical and cyber threats to these assets are intertwined.
- **Environmental failures**: Inadequate power protection or cooling causes data loss and system outages operationally equivalent to a denial-of-service attack.
- **Regulatory exposure**: For PSPF-bound entities, non-compliance results in adverse annual reporting to portfolio ministers and the Department of Home Affairs. For SOCI Act responsible entities, penalties for failing to maintain a compliant Critical Infrastructure Risk Management Program (CIRMP) can be substantial (unverified — confirm the penalty-unit count against the SOCI Act, and note the penalty unit rate is $330 from 7 November 2024, not the $275 figure previously cited).

## Core Concepts

**Defence in depth — physical layers**

Physical security is built in concentric rings. Each layer slows an adversary and creates detection opportunity. If the outermost layer fails, the next layer still applies.

```
+----------------------------------------------------------+
|  OUTER PERIMETER                                         |
|  (fencing, bollards, CCTV, lighting, vehicle barriers)   |
|  +----------------------------------------------------+  |
|  |  BUILDING PERIMETER                                |  |
|  |  (controlled entry points, guards, intercoms)      |  |
|  |  +----------------------------------------------+  |  |
|  |  |  INTERNAL ZONES (PSPF Zone 1–2)              |  |  |
|  |  |  (badge access, visitor escort, reception)   |  |  |
|  |  |  +------------------------------------------+|  |  |
|  |  |  |  RESTRICTED ZONES (PSPF Zone 3–4)        ||  |  |
|  |  |  |  (SCEC locks, Class 5 alarms, dual-auth) ||  |  |
|  |  |  |  +--------------------------------------+||  |  |
|  |  |  |  |  HIGH-SECURITY ZONES (PSPF Zone 5)   |||  |  |
|  |  |  |  |  (ASIO-T4 certified, TOP SECRET,     |||  |  |
|  |  |  |  |   ASD accreditation, SCIFs)          |||  |  |
|  |  |  |  +--------------------------------------+||  |  |
|  |  |  +------------------------------------------+|  |  |
|  |  +----------------------------------------------+  |  |
|  +----------------------------------------------------+  |
+----------------------------------------------------------+
```

**Deter–Detect–Delay–Respond**

The standard operational model for physical security design. Each layer of physical control contributes to one or more functions:

```
DETER          DETECT            DELAY              RESPOND
----------     ----------        ----------         ----------
Lighting       CCTV              Fencing            Guards
CCTV cameras   Motion sensors    Locks/deadbolts    Alarms
Guard presence Access logs       Mantraps           Police/security
Warning signs  Alarm systems     Bollards           Incident team
Perimeter      Patrol reports    Reinforced doors
fencing        PIDS              Security containers
```

The critical design principle: delay must always exceed response time. If alarm response takes 10 minutes, delay controls must hold an adversary for longer than 10 minutes.

**Control categories**

Physical controls sit within the broader control taxonomy used across ISACA and ISC2 frameworks:

```
PREVENTIVE       DETERRENT        DETECTIVE        CORRECTIVE
-----------      ---------        ---------        ----------
Locks            CCTV cameras     Motion sensors   Guards responding
Fences           Security guards  Access logs      Alarms escalating
Mantraps         Warning signs    Audit trails     Isolating systems
Card readers     Lighting         Intrusion IDS    Revoking access
```

**Authentication factors for physical access**

Physical access authentication mirrors logical access — something you have (access card), something you know (PIN), something you are (biometrics). Under the PSPF entity facilities requirements, Zone Five areas require dual-factor authentication as a mandatory minimum.

**CPTED — Crime Prevention Through Environmental Design**

CPTED applies urban design principles to reduce security risk without technology. Natural surveillance (clear sightlines remove hiding places), natural access control (architecture channels movement), territorial reinforcement (demarcation of space), and maintenance (well-maintained environments signal active oversight) all reduce risk at low cost. CPTED decisions are made during facility planning, not retrofitted.

**Environmental threats**

Physical security encompasses non-adversarial threats. Fire, water ingress, power failure, extreme temperature, and electromagnetic interference are genuine threats to hardware and information. Under the SOCI Act CIRMP Rules, natural hazards must be addressed alongside physical security hazards — they are treated as a single hazard category. Redundancy — dual power feeds, UPS, generators, HVAC — is physical security design.

### PSPF Physical Security Requirements

The PSPF Release 2025 sets out two mandatory physical security outcomes for Commonwealth entities:

1. Each entity provides a safe and secure physical environment for their people, information, and assets.
2. Physical security measures minimise or remove the risk of: information and physical assets being made inoperable, inaccessible, or accessed, used, or removed without authorisation; and harm to people.

Entities must integrate protective security during planning, selection, design, and modification of facilities — not post-build.

**PSPF Security Zones 1–5**

Zone classification drives all downstream decisions about construction, alarm systems, access control, and certification.

```
ZONE   TYPICAL USE                        KEY CONTROL REQUIREMENTS
-----  ---------------------------------  -------------------------------------------
1      General office, reception          Basic access control, visitor sign-in
2      Offices with OFFICIAL: Sensitive   Controlled access, ID cards, perimeter lock
3      Areas with PROTECTED info          SCEC locks, Class 5 alarm (AS/NZS 2201.1),
                                          SCEC-approved detection devices
4      Higher classification holdings     SCEC-approved equipment throughout,
                                          dual-factor access, SCEC Zone Consultant
                                          required for Type 1A SAS design
5      TOP SECRET, SCIFs                  ASIO-T4 certified construction,
                                          SCEC Type 1 SAS, ASD accreditation,
                                          dual-factor authentication mandatory
```

**Certification and accreditation**

Security zones must be certified before operational use:

- **Zones 1–4**: Certified by the entity's Certification Authority in accordance with the PSPF and applicable ASIO Technical Notes. Certification is time-limited and requires periodic recertification.
- **Zone 5**: ASIO-T4 certification required. Recertification at minimum every five years. Where the zone holds compartmented information, ASD accreditation is additionally required.
- **Outsourced ICT facilities**: ASIO-T4 physical security certification required where facilities hold information with a catastrophic business impact level.

**SCEC — Security Construction and Equipment Committee**

SCEC evaluates and endorses security equipment for Australian Government use:

- Maintains the Security Equipment Evaluated Products List (SEEPL) — the approved catalogue of containers, safes, locks, and alarm components.
- SCEC-approved containers (Class A, B, C) are required for storage of classified information at relevant business impact levels.
- SCEC-endorsed Security Zone Consultants are required for design, acceptance testing, and commissioning of Type 1A Security Alarm Systems. Consultant endorsement expires every five years.

**ASIO-T4**

ASIO-T4 is Australia's national authority for physical security certification of facilities where compromise would cause catastrophic business impact. Also provides Technical Surveillance Countermeasures (TSCM) services to detect covert listening devices in classified discussion areas.

**Facility Security Plan**

PSPF requires each entity to develop and maintain a Facility Security Plan (FSP) based on a security risk assessment. The FSP must document zone design, access controls, alarm systems, guard arrangements, emergency procedures, and zone certification status. It must integrate with the entity's business continuity plan.

**Annual reporting**

Non-corporate Commonwealth entities report physical security compliance annually to their portfolio minister and to the Department of Home Affairs. PSPF Release 2024 shifted from a maturity-based to a compliance-based reporting model. The 2024–25 PSPF Assessment Report found 92% of entities reported overall effective compliance (unverified — confirm against the PSPF Assessment Report).

### SOCI Act Physical Security Requirements

The SOCI Act 2018 (as amended by the Security Legislation Amendment (Critical Infrastructure) Act 2021, the SLACIP Act 2022, and the ERP Act 2024) covers 11 critical infrastructure sectors and 22 asset classes: energy, communications, data storage and processing, financial services and markets, water and sewerage, healthcare and medical, higher education and research, food and grocery, transport, space technology, and the defence industry.

**Who is a responsible entity?**

A responsible entity is the owner or operator of a critical infrastructure asset as defined under the SOCI Act. Direct interest holders (entities with 10% or greater interest or influence over a CI asset) have separate but related obligations. If you are unsure of your status, the CISC's Critical Infrastructure Asset Class Definition Guidance is the reference document.

**Three Positive Security Obligations (PSOs)**

```
PSO                              KEY PHYSICAL RELEVANCE
----------------------------     ------------------------------------------------
1. Asset Registration            Register physical asset locations and key details
                                 with CISC via the Register of CI Assets
2. Mandatory Cyber Incident      Physical access events that result in a relevant
   Reporting                     impact on a CI asset may trigger reporting
                                 obligations (12-hour initial report to ACSC)
3. CIRMP                         Written, board-approved risk management program
                                 covering physical hazards — see Rule 11 below.
                                 The board-approved annual report and attestation
                                 of CIRMP adequacy (within 90 days of financial
                                 year end) forms part of this CIRMP obligation
```

**CIRMP Rules — Rule 11: Physical and Natural Hazards**

Under the Security of Critical Infrastructure (Critical infrastructure risk management program) Rules (LIN 23/006) 2023, responsible entities must establish and maintain a process or system in their CIRMP to:

- Identify the physical critical components of the CI asset
- Minimise or eliminate material risks from physical security hazards (theft, vandalism, sabotage, unauthorised access to critical components such as control rooms, substations, and plant facilities) so far as reasonably practicable
- Minimise or eliminate material risks from natural hazards (flood, fire, storm, earthquake) so far as reasonably practicable
- Develop and maintain incident response plans for physical and natural hazard events
- Implement security arrangements commensurate with the risk

Physical hazards and natural hazards are addressed as a combined category under the CIRMP Rules. There is no prescribed format or minimum control set — the obligation is principles-based and proportionate to asset criticality, size, and maturity.

**ERP Act 2024 — expanded scope and powers**

The Security of Critical Infrastructure and Other Legislation Amendment (Enhanced Response and Prevention) Act 2024, which received Royal Assent in November 2024 with most provisions effective 20 December 2024:

- Expanded government assistance powers to all serious incidents (not only cyber), reflecting the all-hazards intent — a physical attack on a CI asset now triggers the same government response framework as a cyber attack
- Extended the definition of critical infrastructure assets to include data storage systems holding business critical data, where those systems form part of a CI asset
- Gave CISC the power to direct a responsible entity to vary its CIRMP to address a serious deficiency posing a material risk to national security or social/economic stability
- Consolidated telecommunications security obligations from the TSSR regime into the SOCI Act (effective 4 April 2025)

**Enhanced CIRMP Rules — proposed physical security plan (Exposure Draft, March 2026)**

Following consultation in December 2025, the Department of Home Affairs published an Exposure Draft of Enhanced CIRMP Rules on 25 March 2026 (submissions closed 1 May 2026). Key proposed change for physical security:

Responsible entities for designated high-risk asset classes (currently proposed to include energy market operators, electricity, gas, liquid fuel, water, broadcasting, domain name systems, and freight assets) would be required to **develop and maintain a documented physical security plan** as part of their CIRMP. The proposed plan is explicitly modelled on PSPF facility security plan principles. Proposed compliance date: **30 June 2028**.

This is not yet law. Practitioners in high-risk asset classes should monitor for the finalised rules and begin gap assessment against PSPF-aligned physical security plan requirements now.

**Systems of National Significance (SoNS)**

A small subset of the most critical CI assets may be designated as Systems of National Significance. SoNS entities carry enhanced obligations on top of standard CIRMP requirements, including vulnerability assessments, cyber security exercises, and provision of system information to government. Physical security of SoNS assets receives heightened regulatory attention.

**CIRMP annual reporting**

Board-approved CIRMP annual reports must be submitted to the Secretary of the Department of Home Affairs (or the Reserve Bank for payment system assets) within 90 days of financial year end. The first reports covering FY2023–24 were due 28 September 2024. Reports are an in-house attestation of CIRMP effectiveness — they are not submitted for audit as a matter of course, but CISC has commenced compliance audit activities.

## How It Works in Practice

**Roles and responsibilities**

Physical security spans facilities management (entry systems, HVAC, power), IT security (server room access, media controls), corporate security or guard services (patrols, incident response), and HR (background checks, access provisioning). Under the PSPF, the Chief Security Officer (CSO) is accountable for the Facility Security Plan and physical security compliance. The Accountable Authority (Secretary or Agency Head) reports compliance annually. Under the SOCI Act, the Board is accountable for approving the CIRMP. The CISO, CSO, and Board must work together — physical and cyber obligations are increasingly intertwined.

**Access provisioning and deprovisioning**

Access to secure areas must follow the same rigour as logical access. New starters receive only the access their role requires. Leavers — especially involuntary terminations — must have physical access revoked immediately. Temporary and contractor access requires explicit approval, defined scope, and expiry dates. Under the PSPF, access to areas holding classified information additionally requires a security clearance from the Australian Government Security Vetting Agency (AGSVA). Under the SOCI CIRMP Rules, access to physical critical components by critical workers requires suitability assessment (background checks via AusCheck or an equivalent process documented in the CIRMP).

**Visitor management**

All visitors are logged, escorted, and badged with visually distinct credentials. Escort responsibility lies with the sponsoring employee. Records are retained and reviewed. Classified areas under PSPF cannot be accessed by unclearanced visitors without specific risk-based approval. Under SOCI, access to physical critical components of CI assets must be controlled as part of the CIRMP.

**Typical server room / data centre controls**

```
LAYER           CONTROL
----------      --------------------------------------------------
Entry           Badge + PIN or biometric; mantrap or airlock
Zone status     PSPF Zone 3 minimum for PROTECTED info;
                Zone 4–5 for higher classifications;
                SOCI: control rooms and critical plant require
                equivalent physical access controls in CIRMP
Monitoring      CCTV, motion detection, environmental sensors
Alarm           AS/NZS 2201.1 Class 5 (Zone 3 gov minimum);
                SCEC Type 1 SAS (Zone 5)
Power           Dual feeds, UPS, generator with automatic failover
Cooling         Redundant HVAC; temperature and humidity alarms
Fire            Inert gas or clean agent suppression (not water)
Media           SCEC-approved containers for classified material;
                locked storage for removable media;
                secure disposal with certificate of destruction
Assets          Locked racks; cable locks; tamper-evident seals
Audit           Access logs retained and reviewed; visitor records
TSCM            Sweep assessments for Zone 5 and classified
                discussion areas (PSPF requirement)
```

**Media and equipment disposal**

Decommissioned hardware remains a physical security risk. Hard drives require degaussing, overwriting per ASD ISM guidance, or physical destruction before disposal. For PSPF entities, disposal of media holding classified information must follow minimum protections and handling requirements. For SOCI entities, disposal of assets containing operational data about CI assets is a physical security hazard that must be addressed in the CIRMP. Certificates of destruction must be obtained.

## Common Mistakes and Weaknesses

**Treating physical security as a facilities problem, not a security problem**

When physical security sits entirely with facilities management outside the CSO's remit, access reviews, deprovisioning, and incident escalation fall through the gaps. Under the PSPF, the CSO is explicitly accountable. Under the SOCI Act, the Board is accountable for CIRMP adequacy — including its physical hazard components.

**Scoping physical critical components too narrowly in the CIRMP**

Many organisations focus their CIRMP physical hazard assessment on server rooms and data centres, overlooking operational technology environments, control rooms, remote unmanned sites, substations, water treatment plant, and transmission infrastructure. These are often the most physically vulnerable points of a CI asset and the most consequential to disrupt.

**Failing to deprovision physical access on departure**

Access card deactivation frequently lags behind HR processes for contractors and casual workers. This is a direct insider threat exposure and a failure of the CIRMP's personnel hazard requirements. Under SOCI, access by critical workers to physical critical components must be controlled — this includes prompt deprovisioning.

**Treating zone certification as a one-time event**

PSPF zone certification is time-limited. Entities that do not track recertification deadlines operate zones without valid certification — a direct compliance failure. Zone 5 recertification must occur at minimum every five years. Early engagement with ASIO-T4 is strongly recommended.

**Not specifying SCEC-approved equipment**

Procurement teams specifying security equipment for government facilities may be unaware that SCEC-approved products are required for Zone 3 and above. Non-approved containers, locks, or alarm components result in zones that cannot be certified.

**Physical security systems as a cyber attack surface**

CCTV, access control, and alarm systems are increasingly networked IP-based systems. A cyber attack can deny authorised access, enable unauthorised access, or pivot to the corporate network via a compromised camera or controller. This intersection is addressed by NPSA's Cyber Assurance of Physical Security Systems (CAPSS) programme. Both the PSPF technology domain and the SOCI CIRMP cyber requirements apply to these systems.

**Not integrating physical and cyber incident response**

Under the ERP Act 2024, the government's assistance powers now apply to all serious incidents — not only cyber. A physical attack on a CI asset that causes a relevant impact must be treated with the same urgency as a cyber incident, including triggering CIRMP incident response arrangements. Many organisations still operate separate physical security incident response and cyber incident response processes with no integration.

**Inadequate review of physical access logs**

CCTV footage and access logs have value only if reviewed. Anomalies — access at unusual hours, multiple failed attempts, movement inconsistent with role — go undetected without a defined review process.

**Environmental single points of failure**

Non-adversarial physical events — fire, flood, power failure — are the most likely causes of CI asset disruption. The CIRMP explicitly requires natural hazard risk to be addressed alongside physical security. Single points of failure in power, cooling, or fire suppression represent foreseeable and manageable risks that must appear in the CIRMP.

## Connections to Other Domains

- **[Cyber Governance and Management (1)](01.%20Cyber%20Governance%20and%20Management.md):** Under the PSPF, the CSO and Accountable Authority are responsible for physical security governance. Under the SOCI Act, the Board approves the CIRMP including its physical hazard components. Physical security policy requires defined ownership and accountability at the most senior level.

- **[Cyber Risk Management (2)](02.%20Cyber%20Risk%20Management.md):** Physical threats — break-in, theft, insider access abuse, sabotage, natural disaster — must be assessed and treated. The PSPF requires risk-commensurate zone controls informed by a security risk assessment. The SOCI CIRMP is built from an all-hazards material risk identification exercise. Physical risk cannot be managed separately from cyber risk — they share the same infrastructure.

- **[Legal, Regulatory, and Compliance (3)](03.%20Legal,%20Regulatory,%20and%20Compliance.md):** The PSPF creates mandatory obligations for Commonwealth entities with annual reporting. The SOCI Act imposes penalties of up to $275,000 per day for non-compliance with CIRMP obligations. PCI DSS Requirement 9 applies to payment card environments. The Privacy Act 1988 (Cth) requires physical safeguards for personal information held by government agencies.

- **[Privacy and Data Protection (4)](04.%20Privacy%20and%20Data%20Protection.md):** Printed documents, unlocked screens, and unshredded materials are physical privacy risks. Physical disposal of records holding personal information is subject to both PSPF minimum protections and Privacy Act obligations. SOCI CIRMP must address disposal of assets containing operational information about CI assets.

- **[Vendor Management (5)](05.%20Vendor%20Management.md):** PSPF Release 2024 introduced explicit third-party risk management requirements, including physical access by suppliers. ASIO-T4 certification applies to outsourced ICT facilities. The SOCI CIRMP must address supply chain risks — physical access by third-party service providers to CI assets is a direct physical hazard.

- **[Asset and Change Management (6)](06.%20Asset%20and%20Change%20Management.md):** Physical security protects the physical assets in the inventory. Hardware decommissioning, secure disposal, and lifecycle management of SCEC-approved containers and CI asset components are joint responsibilities of asset management and physical security.

- **[Identity and Access Management (8)](08.%20Identity%20and%20Access%20Management.md):** Physical access control systems are an IAM problem in hardware. The PSPF links physical and personnel security through security clearance requirements for access to classified zones (AGSVA). The SOCI CIRMP links physical access to critical components to critical worker suitability assessment via AusCheck or equivalent.

- **[Security Operations and Monitoring (12)](12.%20Security%20Operations%20and%20Monitoring.md):** Physical security events — door alarms, CCTV triggers, access anomalies, perimeter intrusion detection — must feed into security monitoring. Under both the PSPF and the SOCI Act's all-hazards incident response requirements, these events must not be siloed from cyber monitoring.

- **[Incident Management and Business Continuity Planning (13)](13.%20Incident%20Management%20and%20Business%20Continuity%20Planning.md):** The PSPF requires the FSP to integrate with the entity's BCP and include emergency management plans for a broad range of scenarios. The SOCI CIRMP requires incident response plans for physical and natural hazard events. The ERP Act 2024 means the government's Part 3A assistance powers can now be triggered by any serious physical incident affecting a CI asset — entities need to understand how this interacts with their own incident response procedures.

- **[Cloud Management (14)](14.%20Cloud%20Management.md):** Under the PSPF and the Australian Government Hosting Certification Framework, cloud providers hosting classified information must meet physical security requirements and be IRAP-assessed. Under the SOCI Act, data storage systems holding business critical data in connection with CI assets are now deemed part of the CI asset itself (ERP Act 2024) — physical security of those systems is within scope.

- **[Cyber Architecture (17)](17.%20Cyber%20Architecture.md):** Secure architecture includes physical segmentation. Network demarcation points, comms rooms, and rack layouts are physical architecture decisions with security implications. PSPF zone design is an architectural decision made during facility planning. SOCI CIRMP physical component mapping informs where architectural separation and hardening are required.

- **[Cyber Culture and Education (18)](18.%20Cyber%20Culture%20and%20Education.md):** Tailgating, clear desk compliance, visitor escort, and removable media hygiene all depend on employee behaviour. Both the PSPF and the SOCI Act require security awareness relevant to the entity's risk environment. Physical controls are only as effective as the culture supporting them.
